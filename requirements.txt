# Runtime dependencies for the meteorological water-phase nucleation layer.
#
# The validated physics core (unified_h2o_nucleation_climate) is bundled in this
# repo and is imported whenever the package loads. That core imports numpy,
# scipy and matplotlib at import time, so all three are REQUIRED just to run the
# module — even for a plain CLI report. Only the NetCDF/GRIB I/O extras are
# optional (they are imported lazily, on demand).

# --- Required -------------------------------------------------------------
numpy>=1.20
scipy            # core: Brent root-finding (scipy.optimize.brentq)
matplotlib       # core: imported at load (uses the headless "Agg" backend)
threadpoolctl    # meteorological_flow: runtime BLAS/OpenMP thread control (--compute-threads)

# --- Optional (GPU acceleration for meteorological_flow, --device gpu) ----
# cupy-cuda12x   : install manually if you have an NVIDIA GPU; see
#                  `pip install met_water_nucleation[gpu]` / pyproject.toml.
#                  Never required for CPU-only use.

# --- Optional (NetCDF / GRIB ingestion & export) --------------------------
# xarray   : NetCDF ingestion & report export (example_met_xarray_netcdf.py)
# netCDF4  : NetCDF4 backend for xarray
xarray
netCDF4

# --- Optional (GRIB ingestion) --------------------------------------------
# Uncomment to enable reading GRIB fields via xarray's cfgrib backend.
# cfgrib
# eccodes
